Time Management App
独自の制約ロジック（連続選択制限）を組み込んだ、AI活用型時間管理Webアプリ。

開発の目的
自宅学習における集中力低下という自身の課題を解決するため、「人間の行動心理（強迫観念と強制制限）」をシステム要件に落とし込んだMVP（プロトタイプ）として開発しました。

使用技術
言語/フレームワーク: Python, Streamlit

開発パートナー: 生成AI (ChatGPT/Claude)

開発のこだわり（Technical Highlights）
制約ロジックの実装: 「勉強」と「娯楽」からランダムに選択肢を提示し、娯楽の連続選択をシステム制御でロックする独自のアルゴリズムを設計しました。

UI/UX設計: 勉強への没頭を促すため、あえてタイマーを非表示にするなど、人間の心理的ハードルを考慮した情報設計を行いました。

高速プロトタイピング: 開発効率を最大化するため、生成AIを技術パートナーとしてフル活用。要件定義をAIに指示し、返ってきたコードを自身のロジックと結合するプロセスで、わずか2週間でMVPを構築しました。

今後の展望
友人へのテスト利用フィードバック（ユーザー検証）に基づき、現在UIの改善サイクルを回しています。今後はデータベース連携による学習ログの蓄積と、分析機能の追加を予定しています。
