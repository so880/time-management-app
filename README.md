# ⏳ 集中力最大化・時間管理Webアプリ (MVP)

## 🎯 開発の背景 (Background)
自宅学習において「娯楽への逃げ」による集中力低下が最大の課題でした。既存のタイマーアプリやポモドーロ手法を試しましたが、これらは「何をするか」という選択権がユーザーに委ねられているため、意思の弱い状況下では根本的な解決に至りませんでした。
私は、集中できる環境として「図書館」に注目し、その本質が「行動選択の自由度の低さ（制約環境）」にあると分析しました。本プロジェクトでは、この「制約環境」を自宅のPC上で疑似的に再現し、システムがユーザーの行動をガイドするアプリを開発しました。

## 💡 独自の制約ロジック (Core Logic & Features)
単なる計測ツールではなく、人間の心理的ハードルを考慮した以下の4つの機能要件を定義しました。

1. **ランダム提示機能**
   - 行動選択時の迷いを減らすため、「勉強」と「娯楽」をシステム側がランダムに提示。
2. **連続選択ロック機能**
   - 「娯楽」を連続して選べないよう制限し、システムによる強制的・心理的ガードレールを構築。
3. **可変的タイマーUI**
   - 勉強中はタイマーを非表示にし、時間に対する強迫観念を排除して目の前の課題への集中（没入）を促進。
4. **目標期日までの使用可能時間算出機能**
   - 期限という曖昧な概念を「あと何時間」という具体的な数値に変換し、達成へのモチベーションを可視化。

## 🛠 技術スタック (Tech Stack)
- **Framework:** Python (Streamlit)
- **Development Partner:** Gemini (生成AI)
  - アルゴリズムの複雑な状態遷移ロジックをプロンプトエンジニアリングによって定義し、企画から2週間でMVPを実装。
