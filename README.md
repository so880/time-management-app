# ⏳ 環境制御型 時間管理Webアプリ (MVP)

## 🎯 概要 (Overview)
「娯楽への目移り」による集中力低下という課題に対し、人間の心理的ハードルをシステム側で補完するために企画・開発した時間管理Webアプリケーション（MVP）です。
既存のタイマーアプリが抱える「行動選択の自由度が高すぎる」という根本課題を解決するため、ユーザーの選択肢を強制的に制限する独自のロジックを実装しています。

## 💡 コア機能 (Core Features)
本アプリは単なるタイマーではなく、行動心理に基づいた以下の制約ロジックを持っています。

1. **行動のランダム提示機能**
   - 行動選択時の迷いや心理的負荷を排除するため、「勉強」と「娯楽」をシステム側がランダムに提示します。
2. **状態管理による連続選択の制限**
   - 意思の弱さをシステムでカバーするため、一度「娯楽」を選んだ後は連続して娯楽を選べないよう状態遷移を制御しています。
3. **没入型UI（フロー状態の促進）**
   - 娯楽時はタイマーを表示して時間を意識させる一方、勉強中はあえてタイマーを非表示にし、目の前の課題への没入を促進します。

## 🛠 技術スタックとアプローチ (Tech Stack & Approach)
- **言語・フレームワーク:** Python / Streamlit
- **開発アプローチ:** 仮説検証（MVP構築）のリードタイムを極限まで短縮するため、生成AIを開発パートナーとして活用。複雑な状態遷移ロジックやUI要件を言語化し、プロンプトベースでアーキテクチャを設計・実装しました（企画から約2週間で初期リリース）。
